# 学习终端 · 本地工作台

运行入口：本目录 `start.cmd` 或 `python launch.py`。需要 Python 3.10+，基础功能无需安装第三方依赖。默认以 Edge 独立窗口打开；缺少 Edge 则使用系统浏览器。不是 Electron 安装包。

## 当前可用

- 普通待办新增、编辑、筛选、截止日期、优先级、关联学习会话和前置任务。
- 本地调度：明确派发后排队；前置任务验收完成后才执行；支持暂停、取消、结果登记、验收、重新打开及事件历史。
- 学习记录以 SQLite 只读连接读取已有会话及最新讲解版本，按更新时间显示；通过本机 Taber bridge 打开。桥接返回不替代用户目视验收，失败如实记录。
- 本地入口检查可直接运行；Agent 提供具名人工交接、提示词复制和结果回收，没有后台模型调用。
- JSON 全量导出任务和事件。数据库重启持久化；中断执行标为结果未知，排队任务恢复为暂停，不自动重放。

## 数据与运行

`data/hub.sqlite3` 只保存工作台新增任务与事件，与 `.learning-terminal/learning.sqlite3`、`study-support.sqlite3` 分离。普通待办完成不会更新作业或掌握记录。现有学习库只读，不新增会话、不处理录音。schema 当前为版本 2；支持任务交接包导入，不提供全量数据库恢复或合并。

服务仅监听 `127.0.0.1:8790`，每次启动生成随机访问凭证，验证 Host、Origin 与 API token。启动入口可复用已运行实例；凭证在 `data/runtime.json` 中仅用于本机窗口启动，不应分享或纳入 Git。关闭窗口不会停服务；左下角“停止本地服务”可显式停止。没有安装开机自启或计划任务。

如启动失败，查看 `startup-error.txt`；端口被其他程序占用时不会终止该程序。也可使用 Python 3.10+ 在本目录运行 `python launch.py`。调度处理使用单 worker，避免同一实例并行执行同一任务；不支持多实例共写同一工作台库，默认启动器通过固定端口限制实例。

取消正在执行的桥接会终止桥接进程，但已产生的外部效果（如 Taber 已打开）不回滚。未知结果必须核对并登记，之后才能决定重开。已完成前置任务被重开后，后续未完成任务的执行/验收会受阻；历史已验收记录保留。

## 分工与未接入部分

Codex 所有：`hub/`、`web/`、启动器、核心测试；Qoder 所有：现有协议项目中的抓取/监听/收发及工具适配层。Qoder 不需要为本工作台另建桌面壳。

2026-10-17 工具中心已接入 Qoder 的 `http://127.0.0.1:8787/api`：工具清单与实时状态、单次执行、试运行、启停周期、历史运行、材料投递状态及单条 held 补发。页面动作先进入工作台任务，再调用工具服务。状态为 waiting_tool 时仅查询已有 runId，不占用主执行队列；重启后继续查询，不重复提交。completed 进入待验收，failed 为执行失败；与材料的 held/pending/served/acked 分开显示。

服务离线时明确提示且不显示操作按钮。请使用协议项目现有启动入口，工作台不会自动启动该服务或另建周期调度。dirwatch 的 watchDir 仍需由服务配置指定，现有 API 不支持修改目录。停用周期不取消正在运行的操作；Qoder API 没有取消接口。补发只允许用户明确选择的一条材料，不提供默认全量补发。

工作台的 requestId 在本地去重；远端接口不支持幂等键。提交后连接断开、超时、响应不可读或服务端错误一律记为结果未知，不自动重发。已知 runId 查询断线仍保留并继续查询；远端记录 404 则标记结果未知（服务仅保留最近 300 条历史），需人工核对。不会因工具 retryable=true 自动再次提交，周期退避由 Qoder 后端维护。

Agent 支持本机注册、轮询、心跳以及显式跨端文件交接；尚未连接远端持续通信或按额度路由。调度核心已具备依赖与验收，但还不是自主规划 Agent。本轮不调用收费模型进行测试。

## 验证

`python -X utf8 -m unittest discover -s tests -v`

`node tests/ui.cjs`（需本机已有 Playwright 和 Edge，脚本支持 PLAYWRIGHT_PACKAGE/HUB_PYTHON 环境变量）

UI 测试使用 tests/artifacts 下独立数据库；不在真实工作台中加入测试任务，不运行实际 Taber 打开动作，也不发送 Agent 消息。真实学习目录读取及本地入口检查会实际运行。


双端主机和任务协作设置见 [AGENT-CONNECT.md](AGENT-CONNECT.md)。新增端到端页面测试：`node tests/collaboration-ui.cjs`（通过 `PLAYWRIGHT_MODULE` 指定 Playwright，`HUB_PYTHON` 指定 Python，`BROWSER_CHANNEL` 默认为 chrome）。
