2026-10-17 已按 `<external-tool-service>/INTERFACE.md` 的实际契约完成适配，见 `hub/toolcenter.py`。Qoder 保留工具后端所有权；本轮未改其源码。以下为原接口建议，实际差异以上方日期及下节为准。

## 当前实际接口差异

- 端口 8787，本机直连免 token；工作台服务端固定访问 127.0.0.1，浏览器不直接访问工具服务，不读取或传递 config.json 凭据。
- POST run 返回 202/runId；工作台持久保存后进入 waiting_tool，并独立查询 GET runs。远端 completed 映射 review；失败映射 failed；不得等同 iOS acked。
- 远端不提供 request_id 幂等能力，也没有取消接口。工作台只做本地操作意图去重；提交结果不明时转 unknown，禁止自动重发。周期启停不是运行取消。
- 工具配置修改（包括 watchDir）不在现有 HTTP 能力中，不制作虚假的配置表单。材料补发只提交选中 sha256，不提交 all。
- 运行记录有限保留，找不到既有 runId 时按结果未知处理，而不是自动执行一次新的任务。

## 调用边界

工具目录项：稳定 `tool_id`、名称、说明、能力、配置字段、是否有副作用、是否支持取消、当前启用状态及状态采样时间。读取工具目录不启动抓取或模型。

操作：查询配置/状态、显式启动单次运行、启用或暂停长期监听、查询某次运行及结果；不存在的能力返回不支持，不能用启动成功替代执行成功。

运行请求含 `request_id`（幂等键）、`task_id`（工作台关联）、`tool_id`、`operation`、经过字段验证的参数。工具返回 `run_id` 与当前状态，重复 request_id 返回原运行，不重复抓取或投递。

运行结果含 `run_id`、`request_id`、状态、开始/结束时间、摘要、结构化产物（路径/哈希/角色）、可展示错误与是否可重试。抓取已完成、待投递、已提供下载、iOS 已确认分别记录。工作台将成功结果置为待验收，不据此写入学习掌握记录。

服务重启时：可查询原 run_id；查不到时明确结果未知。不能把连接中断自动等同失败后重试。周期监听属于工具后端的确定性调度，与工作台的高层任务依赖分别管理，不重复部署第二个监听器。

推荐本机受认证接口或无 shell 拼接的 CLI JSON 协议。传输选型由现有服务决定。请交付真实 endpoint/命令、请求响应样例（无凭据）、认证读取方式、超时和取消语义、测试证据。工作台不会开放任意 shell 执行接口。
